# Codex Handoff Template

Use this exact structure after every completed task.

## 1. Goal
What task was supposed to be completed.

## 2. Source-of-truth documents used
List the exact master/module/schema/task files that governed the work.

## 3. Files created
List each new file.

## 4. Files updated
List each modified file.

## 5. What was implemented
Describe the completed work in direct bounded terms.

## 6. What was intentionally not changed
State what remained untouched to preserve scope.

## 7. Acceptance criteria status
For each acceptance criterion from `NEXT_TASK.md`, mark:
- completed
- partially completed
- not completed

## 8. Risks or follow-up notes
List only real remaining risks, edge cases, or follow-up constraints.

## 9. Required state synchronization
Confirm whether the following were updated and why:
- `01_MASTER/CURRENT_STATE.md`
- `05_CODEX/TASKS.md`
- `05_CODEX/CODEX_WORKLOG.md`
- `05_CODEX/NEXT_TASK.md`
- any navigation or SSOT files

## 10. Recommended next step
State one bounded next step only.
